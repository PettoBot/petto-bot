# Support

For setup questions, configuration help, and reproducible bugs, search the
documentation and existing GitHub issues first. If no answer exists, open a
clear issue with the version, expected behavior, actual behavior, relevant
logs with secrets removed, and reproduction steps.

Use a proposal issue or discussion before implementing a feature or behavior
change. Use [SECURITY.md](SECURITY.md) for vulnerabilities; security reports
must not be posted publicly.

Never upload `.env` files, tokens, cookies, database URLs, private user data,
or unredacted production logs when requesting support.
