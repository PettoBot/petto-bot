# Fonts

The fonts used by image cards, in the Latin subset, as WOFF2. They come from the Fontsource packages
(https://fontsource.org) and keep their own licenses.

- Poppins, Inter, Montserrat, Oswald, Playfair Display, Roboto Mono, Fredoka, Caveat, Bebas Neue, Anton, Pacifico,
  Lobster, Press Start 2P, Righteous, Bangers: SIL Open Font License 1.1.
- Permanent Marker: Apache License 2.0.
- Nunito, Quicksand, Space Grotesk, Orbitron, Dancing Script, Comfortaa, Rubik, Russo One, Cinzel, Abril Fatface, Satisfy, Shadows Into Light, VT323, Audiowide, Baloo 2, Bungee, Chewy, Creepster, Special Elite, Great Vibes, Kanit, Archivo Black, Lilita One, Staatliches: SIL Open Font License 1.1 (Special Elite: Apache License 2.0).
